# Telas do BioByte Sentinela v5

Capturas usadas pelo roteiro `../roteiro_narrado_v5_biobyte.md`. O gerador de vídeo lê o
roteiro, abre a tela indicada em cada cena e narra o texto.

Todas foram tiradas da interface rodando, contra o banco `biobyte_v5_app` com dois casos
clínicos plantados. Nenhuma é montagem.
